\# Mi Biblioteca



Launcher y catálogo de juegos para Windows desarrollado con Electron.



\## Características



\- Catálogo visual de juegos.

\- Portadas personalizadas.

\- Añadir juegos desde archivos `.exe`.

\- Editar juegos.

\- Eliminar juegos.

\- Buscador.

\- Ejecución directa de los juegos.

\- Indicador de juego en ejecución.

\- Interfaz oscura.

\- Icono personalizado.

\- Almacenamiento de la biblioteca fuera de la aplicación.



\## Tecnologías



\- Electron

\- JavaScript

\- HTML

\- CSS

\- Font Awesome

\- electron-builder



\## Requisitos para desarrollo



\- Node.js

\- npm
